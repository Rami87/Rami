Testing your backup: five steps to peace of mind

Many businesses have a backup and do not know whether it works. A short test brings clarity.

1. Know what is backed up

Write down which data is important: patient or customer data, documents, email, accounting. Check that exactly these folders and programs are included in the backup.

2. Check that the backup runs

Look in the log to see whether the last backup succeeded and when it took place. An error message or a date from weeks ago is a warning sign.

3. Restore one file

Restore a single, unimportant file from the backup and open it. It takes a few minutes and shows whether the path works in principle.

4. Think through the emergency

How long would it take until you can work again if a device fails? Who knows how to start the recovery, and can that person be reached on holiday?

5. Have a second location

If the backup sits in the same room as the original data, it does not protect against fire, theft or encryption by malware. A copy in another place or in a separate cloud closes this gap.
