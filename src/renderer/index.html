Datensicherung

Sichern Sie Ihre Daten, damit sie bei einem neuen Computer nicht verloren gehen.

Sicherung erstellen

Speichert Einstellungen, Logo und alle Rechnungen in einer Datei. Legen Sie sie auf einen USB-Stick oder in die Cloud.

Sicherung wiederherstellen

Wählen Sie eine Sicherungsdatei. Sie können die Daten zusammenführen oder alles ersetzen.

Alle Rechnungen als PDF

Erstellt für jede Rechnung eine PDF-Datei in einem Ordner Ihrer Wahl, z. B. für den Steuerberater.

Wo liegen meine Daten?

Die Daten liegen nicht in der exe-Datei, sondern in diesem Ordner auf dem Computer:

Umzug auf einen neuen Computer

  1. Hier eine Sicherung erstellen und die Datei mitnehmen.
  2. Die exe-Datei auf dem neuen Computer starten.
  3. Unter «Sicherung wiederherstellen» die Datei auswählen.
