# برنامج الفواتير

برنامج مكتبي بسيط (Electron) لكتابة الفواتير وحفظها بصيغة PDF وأرشفتها. يعمل بالكامل بدون إنترنت، والبيانات تُحفظ محلياً على جهاز المستخدم. ليس برنامج محاسبة.

## المزايا
- الواجهة والفاتورة بالألمانية وفق القانون النمساوي: ضريبة 0/10/13/20% وتاريخ الخدمة ورقم UID وIBAN؛ الافتراضي «Umsatzsteuerfrei gemäß § 6 Abs. 1 Z 27 UStG.»
- إنشاء فاتورة (عميل، بنود، خصم، ضريبة، ملاحظات) مع معاينة مباشرة
- تصدير PDF
- أرشيف للفواتير: اختيار يوم/شهر/سنة مع المجاميع، بحث، تعديل وحذف، معاينة وطباعة وتصدير CSV
- رقم الفاتورة تلقائي بصيغة TTMMJJ01 (مثل 02102601)
- قسم Datensicherung: نسخة احتياطية واسترجاع بملف واحد، وتصدير كل الفواتير PDF
- إعدادات: اسم الشركة، العنوان، اللون الأساسي، الشعار، العملة، الضريبة الافتراضية، وقائمة بنود جاهزة تظهر عند كتابة البند

## التشغيل
```
npm install
npm start          # تشغيل البرنامج
npm test           # اختبارات التخزين والقالب
npm run sample     # ينتج sample/*.pdf
npm run dist       # ملف .exe محمول لويندوز في dist/ (يُبنى على ويندوز)
```
البيانات: `%APPDATA%/invoice-app/data/` (ملفا JSON: settings.json و invoices.json).
